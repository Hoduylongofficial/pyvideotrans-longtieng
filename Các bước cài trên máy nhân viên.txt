Các bước cài trên máy nhân viên:

Giải nén zip ra ổ đĩa (ví dụ D:\pyvideotrans-longtieng)
Cài uv và ffmpeg — mục 1.1 và 1.2 trong HUONG_DAN_LONG_TIENG.md
Mở PowerShell trong thư mục đó, chạy uv sync (lần đầu 10–20 phút, tải vài GB)
Bấm đúp MO_PHAN_MEM.bat → menu kênh dịch → OpenRouter → dán key → lưu
Từ đó dùng LONG_TIENG.bat như thường

Cập nhật khi quản lý sửa code:
Đóng MO_PHAN_MEM / LONG_TIENG, bấm đúp CAP_NHAT.bat.
Lần đầu nó hỏi token GitHub — xin quản lý rồi dán vào (chỉ hỏi 1 lần).
API key và kênh dịch đã chọn trên máy được giữ nguyên.

Đổi model / thêm API key: bấm đúp DOI_MODEL.bat (xem mục 1.5b trong HUONG_DAN_LONG_TIENG.md)

Lần chạy đầu tiên sẽ tự tải model tách nhạc UVR (59 MB), nên máy nhân viên cần có mạng.
